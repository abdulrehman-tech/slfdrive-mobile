## Notes & compliance
- **App name consistency:** the on-device name is **SLF Drive**; the store name adds a keyword suffix, which both stores allow.
- **Arabic RLM:** the `‏` prefix on the Arabic app name is a right-to-left mark so the Latin "SLF Drive" and Arabic text order correctly. Paste as-is; if the console shows a stray character, delete the leading mark.
- **No superlatives / rankings** (e.g. "#1", "best") — both stores can reject these without proof.
- **Screenshots carry the visuals** — keep promo text benefit-focused; see `STORE_DEPLOYMENT.md` §4 for required sizes.
- **Localization:** add Arabic as an additional listing language in each console (App Store Connect → App Information → add Arabic; Play Console → Store listing → Manage translations → Arabic).
```
